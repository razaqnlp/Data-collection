# Data Collection

> **Status: 🚧 In progress.** Data collection is not yet complete.

This repository is the home of an ongoing data collection effort for NLP research. The dataset is still being gathered, cleaned, and verified, so the raw data and final files are **not published here yet**.

## Current Status

- Collection is ongoing and the dataset is not final.
- Cleaning, filtering, and quality checks are still in progress.
- Dataset size, structure, and documentation may change before a public release.

## Access to the Data

If you are a researcher, student, or collaborator and would like access to the data collected so far, along with information about how it was collected, **it is available on request.**

To request access:

1. Open an [issue](../../issues) in this repository, or contact me through my [GitHub profile](https://github.com/razaqnlp).
2. Briefly describe who you are and how you plan to use the data.

I will share the total collected data and the related collection details as soon as I can.

## What to Expect Next

- A full description of the collection method and sources
- Dataset statistics and structure
- Cleaning and quality-control documentation
- A public release of the finalized dataset, where appropriate

## Responsible Use

Please use any shared data for research and educational purposes only, respect the privacy of the people who produced it, and do not attempt to identify individuals. If you use the data in your work, please credit this repository.
